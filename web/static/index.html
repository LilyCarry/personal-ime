日常打字时，微信输入法甚至能记住你的专属口癖、并在你二次打自造句时用更少按键直接猜出整句；点击下方案例展开互动，再看它绕不开的三个问题。

反面瓶颈：点击逐条展开核心痛点

聊天记录、账号密码、个人想法全经输入法流过；闭源软件的云端联想与遥测机制让人难以彻底放心数据边界。

面向大众平均习惯构建庞大静态词库与重型本地模型，靠堆内存和算力覆盖所有人，策略固化且资源开销大。

只能粗粒度勾选固定模糊音，既看不清自己真实的声韵母偏差统计，也无法用个人专属语料在本地持续训练模型。

THREAD 03 // PERSONAL-IME HIGHLIGHTS

基于 Rime 的个性化输入法：开源、轻巧、且越用越像你

点击任意一张亮点卡片展开实现机制，或直接顺着文末线索关键词深入对应模块。

站在 Rime（小狼毫）+ 雾凇拼音 + 8105 通用字表 + Qwen3 开源生态之上；Lua 采集器写入前硬拦截 4 位以上数字、@、:// 与密钥前缀，所有数据与模型留在本地。

大多数人其实说不清自己是 l=n 还是 ong=on。开局只需盲敲 3 句测速文本，系统自动与标准拼音对齐，从 24 条白名单中编译出专属 Rime 补丁。

日常敲击由 500 条滑动窗口核算每条规则的真实收益（>=15% 开启 / <5% 自动休眠），换键盘或习惯改变后无感热切换并轻提示 3 次。

利用个人日志校准噪声模拟器，周末本地增量微调 Qwen3-0.6B LoRA 或 ~29M 移动端模型，并通过拼音 Trie 约束与亚毫秒 C 桥接嵌入小狼毫。

按照使用时间线，我们先看第 1 步——新用户刚上手时
THREAD 04 // COLD-START RULE PROFILING

开局个性化定制规则：3 句连打捕获手癖 -> 编译 Rime 正则

点击左侧拆解每一步防幻觉机制，并在右侧点选不同规则 ID 实时查看生成的 speller/algebra/+ 补丁。

允许平时怎么顺手就怎么敲（不加空格），用 1~7 字符窗口 + Levenshtein 编辑距离做轻量动态规划，把 zhonguolenmin 精准切回 zhon|guo|len|min。

严禁大模型手写 Rime 正则；仅允许在 24 条词表中选 ID，经 normalize_rule_id 将 zh=z / u=v 归一化并拦截幻觉 ID；超时 >6s 自动切换本地兜底。

包含 7 声母（平翘舌、l=n、l=r、f=h、g=k）、8 韵母（ong=on、前后鼻音）、9 容错（ju=jv、换序 an=na、zh=hz）。
