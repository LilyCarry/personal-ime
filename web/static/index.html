01 // COVER & PAIN POINTS

不改写你的习惯，让输入法学会迁就你

通用云输入法用海量语料训练“平均人”，但每个人的敲击省键、方言口音与键盘误触都高度个性化。Personal-IME 以隐私优先、完全本地化为前提，用规则层 + 端侧小模型打造只懂你一个人的输入法。

翻车现场 A · 省键与后鼻音截断
原始敲击 zhon guo -> 通用词库：众过 / 忠国
手癖简化 wmxqcf -> 期望上屏：我明天去吃饭

快打时习惯性省略后鼻音尾键 g 或只敲声母，通用词库频繁出字错位。

翻车现场 B · 邻键误触与高速换序
邻键偏移 wishi -> 传统匹配：卫士（实为我是 woshi）
左右手倒置 hzi / dna -> 真实意图：知 zhi / 但 dan

高速盲打时左右手时序错位、机械轴连击或邻键蹭键，往往只能整词退格重打。

隐私底线 数据不出本机，日志自动脱敏

Rime 采集插件直接过滤 4 位以上数字、邮箱与密钥前缀，规则与模型权重全部驻留本地。

目标一 · 规则层 量化模糊音 + 日常滑动校准

冷启动识别个人风格，编译为 Rime algebra 规则（如 ong=on），长期无感微调。

目标二 · 神经层 端侧 LoRA + 拼音 Trie 约束

利用个人噪声语料周末本地微调轻量模型，在严格读音约束下直接纠正错拼与简拼。

03 // GOAL 1: QUANTIFIED RULES

目标一原理：风格诊断 -> 量化 Rime 规则 -> 滑动窗口自校准

将模糊的“打字手癖”拆解为可验证、可开关、可回滚的 24 条标准拼音代数规则，不污染主词库即可即插即用。

STEP 01

初次风格识别（冷启动）

对比标准参考拼音与原始敲击串，定位平翘舌、前后鼻音省尾与邻键换序，再由 DeepSeek 生成趣味诊断与白名单规则建议。

ref: zhong guo ren min
raw: zhon guo len ming
STEP 02

量化为 Rime Algebra 规则

所有建议严格映射至标准规则 ID 白名单，杜绝大模型幻觉造词，一键导出雾凇拼音 speller/algebra/+ 补丁。

patch:
  speller/algebra/+:
    - 'derive/ong$/on/'   # ong=on
    - 'derive/^l/r/'      # l=r
    - 'derive/^r/l/'
STEP 03

日常无感切换与画像纠正

日常敲击通过 ime_logger.lua 脱敏记录命中/回改率；滑动窗口定期评估各规则净收益，低效规则自动降权并轻量提醒。

ong=on 收益 +14% l=r 命中 28 次 g=k 自动休眠
规则词表规模 24 条标准离散规则
覆盖维度 声母互通 / 韵母简拼 / 邻键与换序容错
集成方式 小狼毫 Rime 热部署，零推理延迟
04 // GOAL 2: LOCAL LORA & TRIE CONSTRAINED DECODING

目标二原理：Transformer 注意力 + 周末本地 LoRA + 拼音 Trie 约束

规则层解决已知手癖，神经层负责结合上下文解决“既简拼又误触”的复杂错键，同时以读音 Trie 锁死生成边界。
