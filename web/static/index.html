01 // WHY PERSONAL-IME

微信输入法确实很舒服，但输入法这件事，我们想自己掌控

CORE TENSION 顺手体验 ≠ 隐私安全 & 个性可控
体验起点：实测微信输入法的两种聪明（点击右侧卡片逐步展开）
案例 1 · 个人语言习惯
打 ni'ge'c'l'l，记住你的私人高频口癖
1 你个臭乐乐 2 你哥出来了 3 你个出来了
通用词库里排第一的本来是“你哥出来了”，但输入法直接把个人常用口癖推到了首选。
案例 2 · 自造句渐进记忆
第 1 次敲 qian'd'l'kuai'q'c，首推仍偏离原意
1 钱多了快去吃 2 签到了快起床 3 签到了快去吃
对于“签到了快起床”这类个人自造短句，第一次哪怕多敲音节也很难一次命中首选。
现实矛盾：为什么还要自己做一个基于 Rime 的输入法
01

输入法是极度隐私敏感的入口

聊天记录、账号密码、个人偏好与搜索意图全都要经过输入法；闭源客户端的云端联想与遥测，让敏感场景很难完全放心。

02

呆板的通用“空间换时间”

商业输入法面向全网平均习惯堆砌庞大静态词库和重型本地模型，策略固化、资源开销大，无法按个人习惯裁剪。

03

深度定制化程度低

用户通常只能勾选有限的固定模糊音，既看不见自己的声韵母误拼画像，也无法拿个人脱敏语料在本地微调专属模型。

02 // NOISY CHANNEL ARCHITECTURE

商业智能输入法的“噪声信道 + 三级重排”原理

W* = argmax P(W | Context) × P(K | W)

01
开源可控 · 数据不出本机

基于开源库，零黑盒全本地

立足 Rime (小狼毫) + 雾凇拼音 + 8105 字表 + Qwen3，仅通过 Lua 插件与本地推理服务协同；银行卡、邮箱、密钥前缀在写入日志前硬拦截。

rime/lua/* · 8105.dict.yaml · 100% 本地审计
02
开局冷启动 · 告别盲猜

开局个性化定制规则，不用自己猜习惯

绝大多数人分不清自己是 l=n 还是 ong=on。开局盲敲 3 句测试文本，系统对齐标准拼音后直接在白名单内编译专属 Rime 补丁。

03
日常演化 · 防抖不脏栏

使用中智能切换，拒绝候选栏越用越脏

日常敲击通过 500 条滑动窗口 持续核算每条规则的真实收益（>=15% 开启 / <5% 自动关闭），换键盘也能无感自适应并轻提示 3 次。

04
长期沉淀 · 专属端侧小模型

长期使用自动训练个人小模型

用个人脱敏日志校准物理键盘噪声概率，定期在本地自动增量微调 LoRA / 29M 模型，配合 拼音 Trie 约束 与 C 桥接接管重度简拼与错拼。
